# Inl-mningsuppgift-Biograf
Detta är min version av uppgiften "Biografen", där användare själv kan välja vilken film dem vill se, välja antal platser samt priset. Några funktioner som har används för att göra uppgiften är bland annat att markera samt avmarkera säten, blockerar redan bokade säten, multiplicerar priset varje gång extra säten väljs. Filmerna hämtas från en JSON server.
